# Harpreet's Official Poetry Blog 🖋️

Welcome to the source code of my official poetry blog! 

## About This Project
This is a static website created to share my original religious and spiritual poetry with the world. To ensure a global reach and connect with diverse audiences, the poetry is presented in a multi-lingual format:
* **Punjabi** (For my roots and local community)
* **Hindi** (For a nationwide audience in India)
* **English** (For global readers)

## Technologies Used 💻
* **HTML5**: For the structural layout of the poems.
* **CSS3**: For a clean, soothing, and reader-friendly card design.
* **JavaScript**: For interactive background functionalities.
* **GitHub Pages**: For live hosting and deployment.

## The Grand Vision 🚀
This repository is the central node of my content creation. The future goal is to implement an automation system where posting here automatically distributes the content across multiple social media platforms (X, Facebook, Instagram, Threads, Pinterest, Medium, and Discord).
